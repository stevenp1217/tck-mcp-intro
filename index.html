도입 문의 사용 예시

Teamcenter 개발자가 자주 부딪히는 문제들

이 메서드는 어느 class에 있지?

지금은Services API 문서에서 class 페이지를 하나씩 열고 메서드 목록을 확인합니다.

tc-knowledge를 연결하면AI agent가 메서드 이름을 조회해서 class를 찾습니다.

이 설정은 어느 설명서에 있지?

지금은Support Center에 로그인해서 키워드로 검색하고 나온 문서를 하나씩 읽으며 설정을 찾습니다.

tc-knowledge를 연결하면AI agent가 질문과 뜻이 가까운 섹션을 찾아서 본문까지 읽고 알려줍니다.

AI가 짜 준 코드, 공식 문서대로일까?

지금은문서를 다시 찾아서 코드와 하나씩 대조합니다.

tc-knowledge를 연결하면검색 결과마다 원문 링크가 붙어 있습니다.

이 동작을 정하는 preference가 뭐였지?

지금은기능 설명에서 preference 이름을 찾은 뒤 그 이름으로 다시 검색해서 기본값을 확인합니다.

tc-knowledge를 연결하면AI agent가 preference 정의 페이지를 찾아서 이름과 기본값을 함께 알려줍니다.

AI agent가 문서를 검색해서 읽는 방법

AI agent는 도구 3개로 문서를 검색하고 본문과 API 이름을 조회합니다.

섹션 검색에는 Teamcenter 문서로 추가 학습한 검색 모델을 사용합니다.

  • 섹션 검색tc_search_docs

    질문과 뜻이 가까운 섹션을 찾고 결과마다 원문 링크를 붙입니다.

  • 본문 읽기tc_fetch_section

    찾은 섹션은 본문이 길어도 끝까지 가져옵니다.

  • API 이름 확인tc_lookup_symbol

    코드에 넣기 전에 이름이 API reference에 실제로 있는지 확인하고 시그니처를 가져옵니다.

질문과 답 예시

Active Workspace

AW 테이블에 커스텀 속성을 컬럼으로 추가하려면 어디를 고쳐야 돼?

XRT의 objectSet 테이블이면 objectSet에 property로 속성을 추가합니다. 검색 결과처럼 primary work area에 나오는 테이블이면 column configuration에 ColumnDef를 추가합니다. 고친 구성은 import_uiconfig로 다시 등록합니다.

근거
  • Active Workspace Customization > Configuring columns using objectSet properties
  • Active Workspace Customization > Using the command line to manage your column configurations

SBL C#

SBL C#에서 Item 속성 값을 바꿀 때 형식 체크를 넣고 싶은데 어떻게 해?

그 속성의 setter에 PreCondition 확장을 C# 메서드로 붙입니다. 메서드에 PropertySetterPreCondition attribute를 달고 파라미터로 속성 이름을 넣습니다. PreAction과 PostAction도 같은 방식으로 붙입니다.

근거
  • Teamcenter Server Customization in C# - Reference Scripted customization > How to add custom extensions to a string property
  • Teamcenter Server Customization in C# - Reference Scripted customization > Property setter extensions

ITK

ITK로 BOM을 펼쳐서 하위 부품 목록을 읽는 C 코드 예제 있어?

BOM_create_window로 window를 생성하고 BOM_set_window_top_line으로 top line을 정합니다. 하위 line은 BOM_line_ask_child_lines를 재귀로 호출해서 읽습니다. 예제 소스는 TC_ROOT/sample/pse에 있습니다.

근거
  • ITK Function Reference: Bill Of Materials (BOM) > BOM_line_ask_child_lines
  • Teamcenter Server Customization > Sample BOM programs

FAQ

질문이 회사 밖으로 전송되는 거 아닌가요?
tc-knowledge 서버는 질문과 검색 결과를 밖으로 보내지 않습니다. 다만 AI agent가 사용하는 모델 서비스로 무엇을 보내는지는 AI agent의 설정에 따라 다릅니다.
인터넷이 안 되는 서버에도 설치할 수 있나요?
네, 가능합니다. 인터넷 접근 없이도 모든 기능을 사용할 수 있습니다.
사람마다 token을 따로 받나요?
네. 관리 화면에서 사람마다 본인이 로그인한 계정으로 토큰을 발급합니다.
새 버전은 어떻게 올리나요?
설치 가이드를 따라 새 버전의 docker 이미지와 설정 파일을 받아서 교체합니다.
검색 모델은 공개 모델을 그대로 사용하나요?
아니요. 공개 한국어 검색 모델을 Teamcenter 문서로 추가 학습해서 사용합니다. 학습 데이터는 문서 섹션을 보고 모델이 만든 예상 질문 약 51만 개입니다.
GPU가 있어야 하나요?
아니요. GPU가 필요한 학습은 미리 끝냈고 그 모델을 docker 이미지에 넣었습니다. 설치한 서버에서는 CPU로 검색합니다.
